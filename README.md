📈 股票匯率 App

一款以即時資訊為核心的 股票與匯率查詢應用程式，提供使用者快速、直觀的市場概覽。
本專案原作為面試展示使用，現已完成最終版本。

🧭 功能介紹

股票資訊查詢
即時顯示多檔股票的即時價格、漲跌幅與走勢圖。

匯率查詢
支援多國貨幣匯率對比，顯示即時換算結果。

自訂追蹤清單
可將常用的股票或貨幣加入關注清單，方便快速檢視。

清晰的介面設計
採用簡潔直觀的 UI 設計，讓資料呈現更清楚。
